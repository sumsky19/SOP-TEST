SK쉴더스 SOP 숙지평가 프로토타입 v2

구성
- index.html : SOP 숙지평가 웹앱
- data.js : 원본 SOP 관리대장 기반 MASTER/월별 출제 데이터
- manifest.webmanifest / sw.js : PWA용 파일
- icon-*.png / skshieldus-logo.png : 아이콘 및 로고

주요 업데이트
1. 모바일 평가일 입력 영역 폭 보정
2. 평가자 입력 문구를 "피평가자 이름"으로 변경
3. 원문항 내용 표시 크기 및 구분 개선
4. 우측 하단 맨위로 가기 버튼
5. 평가조회 년/월/일/POST 기준 조회
6. 선택/전체 엑셀(.xlsx) 내보내기 + 평가별 체크박스
7. 평가 저장시간 기록/조회
8. 선택삭제/전체삭제
9. 개선관리 별도 메뉴 제거
10~12. SOP 운영기준/평가자 운영·편차관리/공통 채점기준 수정 및 저장
13. 월별 출제관리에서 기본질문/상황질문 색상 구분
14. 평가 MASTER 원문항 내용/표준 질문문구 수정 및 저장
15. 권역관리/구역관리 추가
16. 개별 저장하기 + 현재 설정을 기본값으로 저장
17. 설정 JSON 내보내기/불러오기
18. 평가 완료 후 평가조회가 아니라 첫 화면으로 이동
19. 설정·평가·조회·삭제·엑셀 기능 연동 검증용 구조 적용

주의
- 설정과 평가이력은 브라우저 localStorage에 저장됩니다.
- 새 브라우저/기기에서는 설정 및 평가이력이 공유되지 않습니다.
- 설정 내보내기로 JSON 백업 후 다른 기기에서 불러올 수 있습니다.
